# Careers in Cyber - Notes

## 1. Introduction

Cybersecurity is a field that focuses on protecting computers, networks, applications, and data from cyber threats.

There are many different career paths available in cybersecurity.

## 2. Offensive Security

Offensive security focuses on finding weaknesses in systems by simulating attacks.

Example roles:

* Penetration Tester
* Ethical Hacker
* Red Team Operator

## 3. Defensive Security

Defensive security focuses on protecting systems and detecting cyber attacks.

Example roles:

* Security Analyst
* SOC Analyst
* Incident Responder

## 4. Digital Forensics

Digital forensics involves investigating digital evidence after a security incident.

A forensic investigator may analyze systems, files, logs, and other digital evidence.

## 5. Security Operations

Security Operations teams monitor systems and networks to detect and respond to security threats.

A SOC Analyst commonly works with:

* Security alerts
* Logs
* Network activity
* Security monitoring tools

## 6. Skills Required

Important skills for a cybersecurity career include:

* Networking fundamentals
* Linux
* Windows
* Python
* Cybersecurity concepts
* Problem solving
* Analytical thinking

## 7. Career Growth

Cybersecurity provides different career paths depending on a person's interests and skills.

Some professionals focus on offensive security, while others specialize in defensive security, forensics, cloud security, or other areas.

## 8. Key Learning

I learned that cybersecurity has multiple career paths and that developing strong technical fundamentals is important for entering the field.
